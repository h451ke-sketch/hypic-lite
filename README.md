# 醒图 Lite (Hypic Lite) - 纯本地离线修图与美颜神器

一款基于 **Flutter 3** 打造的轻量级全功能离线修图与人像美颜应用。完全针对个人免费自用设计，**无需任何付费订阅、不调用任何云端收费接口、不上传任何照片到外部服务器、支持 iOS 与 Android 双端**。

---

## 一、 已实现的完整功能清单

### 1. 基础修图与光影调色（GPU 着色器即时渲染）
- **裁切与构图**：自由裁切、1:1（方形/头像）、3:4（人像）、4:3、9:16（竖屏）、16:9（壁纸宽屏）、90° 旋转、水平镜像翻转。
- **光影微调（11 项专业参数）**：
  - 曝光（Exposure）
  - 对比度（Contrast）
  - 亮度（Brightness）
  - 饱和度（Saturation）
  - 自然饱和度（Vibrance）
  - 高光（Highlights）
  - 阴影（Shadows）
  - 色温（冷暖色调 Warm/Cool）
  - 色调（绿/粉平衡 Tint）
  - 暗角（Vignette）
  - 胶片复古颗粒（Grain）
- **贝塞尔曲线（Curves）**：支持 RGB 综合曲线，以及红、绿、蓝三通道独立曲线，触控拖拽添加控制点调色。
- **色彩分离（HSL）**：红、橙、黄、绿、青、蓝、紫、洋红 8 色通道独立调节色相、饱和度、明度。
- **经典胶片与人像滤镜库**：内置日杂清透、冷白皮、奶油肌、港风复古、法式电影、赛博霓虹、质感黑白、暖阳暮色等多种调色预设，支持 0%~100% 滤镜浓度调节。

### 2. 人像美颜与局部重塑
- **质感磨皮**：保留皮肤纹理的平滑去噪算法，抚平细纹与粗大毛孔。
- **冷白美肤**：针对人像提亮，打造自然透亮的白皙肤质。
- **手动液化推脸（核心灵魂功能）**：
  - 支持 **推脸/瘦脸**、**缩小/缩鼻**、**放大/大眼**、**橡皮恢复** 四种微调模式。
  - 支持画笔大小与形变力度自由调节。
  - 在屏幕上直接用手指推拉照片，实现毫秒级即时形变。
- **手动修瑕笔**：点击痘痘、斑点或杂质，自动羽化抚平消除。

### 3. 操作体验与交互细节
- **全分辨率无损导出**：预览采用 GPU 色彩矩阵加速，保存导出时在后台隔离线程全尺寸处理原图，保留完整画质。
- **长按对比原图**：随时长按顶部“长按对比”按钮，即可瞬时切换查看未修图的原图。
- **无限制撤销 / 重做（Undo / Redo）**：完整记录所有调色、滤镜、液化与修瑕操作。
- **开箱即用演示图**：首次启动提供“使用演示人像测试体验”，即使不导入照片也能立即测试所有功能。

## 二、 自动化云端打包（无需本地 Mac 电脑）

本项目已配置好完整版 GitHub Actions 脚本：`.github/workflows/build.yml`。只要将代码推送到你的 GitHub 仓库，微软的云端 macOS 与 Linux 服务器就会**自动免费打包**出安装包！

### 极简操作步骤：
1. 在 [GitHub](https://github.com/) 上新建一个私有仓库（例如 `my-hypic-lite`）。
2. 在本地项目根目录下执行以下 Git 命令：
   ```bash
   git init
   git add .
   git commit -m "feat: complete hypic-lite app"
   git branch -M main
   git remote add origin https://github.com/你的用户名/my-hypic-lite.git
   git push -u origin main
   ```
3. 打开 GitHub 仓库页面，点击上方的 **Actions** 标签页。
4. 你会看到名为 `Build Hypic Lite (Android APK & iOS IPA)` 的自动化工作流正在运行。
5. 等待编译完成（大约 5~8 分钟），在页面底部的 **Artifacts（构建产物）** 中直接点击下载：
   - `hypic-lite-ios-ipa`（解压即得 `hypic_lite.ipa`）
   - `hypic-lite-android-apk`（解压即得 `app-release.apk`）

## 三、 iOS 免费安装与 Sideloadly 7 天自签教程

通过 Sideloadly，你只需要一个**普通的免费个人 Apple ID**，即可将 `hypic_lite.ipa` 免费安装到你的 iPhone 上。

### 1. 准备工作
- 电脑（Windows 或 Mac 均可）下载并安装 [Sideloadly 官网](https://sideloadly.io/)。
- 确保电脑已安装 iTunes / iCloud（Windows 用户在 Sideloadly 官网有下载指引）。

### 2. 安装步骤
1. 用数据线将 iPhone 连接到电脑，在手机上弹出提示时选择**“信任此电脑”**。
2. 打开 Sideloadly，软件会自动识别到你的 iOS 设备。
3. 把从 GitHub 下载解压出的 `hypic_lite.ipa` 拖拽进 Sideloadly 左上角的 IPA 框中。
4. 在 `Apple ID` 处输入你的 Apple 账号邮箱。
5. 点击 **Start** 按钮，按提示输入 Apple ID 密码（仅用于苹果官方证书签名申请，密码不会泄露）。
6. 等待进度条走到 `Done`，App 就会出现在你的 iPhone 桌面上！

### 3. 首次打开手机权限设置
- **信任开发者证书**：手机打开“设置” -> “通用” -> “VPN 与设备管理” -> 点击“开发者 App”（你的 Apple ID） -> 点击**“信任”**。
- **开启开发者模式（仅 iOS 16/17/18 需要）**：手机打开“设置” -> “隐私与安全性” -> 滑到最底部点击“开发者模式” -> 开启并重启手机即可。

### 4. 7天续签说明
由于使用的是免费个人 Apple ID，苹果官方限制签名有效期为 7 天。7 天到期后如果打不开：
- 电脑打开 Sideloadly，插上手机再次点击一次 **Start** 即可秒续签（数据和设置全部保留）。
- 如果手机与电脑处于同一个 Wi-Fi 网络下，Sideloadly 还支持无线局域网自动续签，非常方便。

## 四、 安卓（Android）手机安装方法

安卓设备安装极其简单，没有任何签名限制：
1. 从 GitHub Actions 下载 `hypic-lite-android-apk`。
2. 解压得到 `app-release.apk`，通过微信、QQ、网盘或 USB 传输到你的安卓手机。
3. 在手机文件管理中直接点击安装，即可永久使用！
